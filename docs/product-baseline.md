# Fundamentos do produto

## Propósito

O Cosmetics Hub é uma plataforma de gestão comercial para pequenas empresas e distribuidores de cosméticos. O conceito procura reunir, num só sistema, informação e atividades comerciais que de outra forma ficam dispersas.

## Público

Pequenas empresas, distribuidores de cosméticos e as pessoas que apoiam as suas operações comerciais.

## Problema geral

A gestão de clientes, catálogo, estoque, pedidos e valores a receber pode exigir informação coordenada entre várias atividades. O Cosmetics Hub propõe uma base comum para organizar essas áreas por empresa.

## Áreas do produto

- clientes comerciais;
- catálogo de produtos;
- estoque;
- pedidos;
- valores a receber.

## Limites deste baseline

Este documento regista o conceito geral do produto. Não define requisitos detalhados, regras de negócio, critérios de aceitação, funcionalidades de uma versão específica nem datas ou compromissos de entrega. Esses elementos podem evoluir sem alterar os fundamentos aqui registados.
