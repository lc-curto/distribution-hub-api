# Decisões de arquitetura

Cada ADR registra uma decisão relevante, seu contexto e consequências. “Aceito” significa que a escolha foi registrada; não significa que todos os detalhes estejam implementados.

| ADR | Decisão | Estado |
|---|---|---|
| [ADR-001](ADR-001-modular-monolith.md) | API organizada como monólito modular | Aceito |
| [ADR-002](ADR-002-stack-web-api.md) | React/TypeScript/Vite e FastAPI/Python | Aceito |
| [ADR-003](ADR-003-two-repositories.md) | Exatamente dois repositórios; documentação comum junto à API | Aceito e publicado |
| [ADR-004](ADR-004-oauth2.md) | OAuth 2.0 no nível de framework/protocolo | Aceito; desenho de autenticação pendente |

Detalhes ainda não decididos permanecem em [questões em aberto](../../requirements/open-questions.md), não devem ser inferidos dos ADRs.
